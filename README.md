# Phantom Item (Fabric, Minecraft 26.2)

Клиентский мод. Выбираешь любой предмет в меню: он появляется перед тобой (частицы и звук),
левитирует, затем улетает в руку и остаётся там как призрачный предмет
(виден только тебе, сервер о нём не знает).

- `G` — меню всех предметов: иконки, поиск, прокрутка колесом, подсказка с названием, поле количества
- `H` — повторить последний выбранный предмет
- В меню есть кнопка «Настройки» (частицы появления, левитации и у руки, звуки, громкость, длительность)
- Кнопка «Убрать призрак из руки» возвращает настоящий предмет в руку

Настройки хранятся в config/phantomitem.json.
Сборка: любой push запускает GitHub Actions, jar лежит в артефакте `phantomitem-jar`.
